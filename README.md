# Spacetube Tool

Spacetube tool for Chat Hackers groups.

This tool connects chats to spacetube, to allow cross-group chat.

## Getting started

1. Clone the repo
1. Run the command `npm install`
1. Run the command `npm run dev`
1. Copy the `spacetube.json` file and paste into the `registrations` folder of [the tool hub](https://github.com/chat-hackers/tool-hub)
1. Restart the tool-hub and then paste the gear emoji to see the tools
